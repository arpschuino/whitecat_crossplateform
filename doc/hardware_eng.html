Hardware Configuration

System

White Cat runs on Windows 10 and 11. To be tested on Windows 7 and Windows 8–8.1. No longer works on XP or Vista.

Users with very old machines can download an older version (0.8.x), still available on Christoph Guillermet's website.

Minimum configuration

CPU

  • Theoretical minimum: dual-core 1 GHz
  • Comfortable: any CPU made after 2010

RAM

  • A full show (512 channels, memories, LFOs) fits comfortably within 50–100 MB
  • 1 GB RAM is enough, 2 GB is comfortable

GPU / display

  • SDL2 uses the hardware renderer by default — any card with DirectX 9 or OpenGL 2.0 works
  • An integrated Intel HD Graphics card from 2011 or later is sufficient
  • Minimum resolution: 1280×800

Storage

  • Exe + DLLs + assets: ~350 MB
  • Saved shows: around 100 MB each

In short

  • Any second-hand office PC from 2010 or later running Windows 10 will run WhiteCat without issue.

Ideal configuration

For use in live performance conditions (reliability, responsiveness):

  • CPU — Core i3/i5 6th gen or equivalent
  • RAM — 4 GB
  • GPU — integrated is fine (Intel UHD 620 or better)
  • Storage — SSD
  • Screen — 1920×1080, 15"
  • OS — Windows 10 or 11, 64-bit

In short: a mid-range office laptop from recent years is perfectly adequate. No gaming machine needed.

Testing a computer

If you are buying a dedicated machine, you can test whether WhiteCat runs on it beforehand:

  1. Copy the WhiteCat folder onto a USB stick.
  2. Try running WhiteCat from the stick, in the shop.

Buying tips

  • Prefer a matte screen.
  • Look for a backlit keyboard and a numeric keypad.
  • Disable automatic Windows updates during a show.

Lighting and video on the same laptop

Using VVVV and WhiteCat together, you can run both on the same machine with an i5-class processor and a 1 GB graphics card.

For this kind of use, favour machines marketed as "gaming" laptops, which emphasise 3D graphics performance.
