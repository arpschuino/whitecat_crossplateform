MANIPULATING THE CHANNELS

Whether you are in [Classical], [Patched] or [Channel Views] mode, all these actions can be performed.

Select a channel

  • with the mouse :

To select or deselect a channel, click it.

Click and drag to select a series of channels.

  • with the keyboard :
     Selection : enter the channel number then press [+].
     Deselection : enter the channel number then press [-].
     ! Note that any string you type is displayed in the information feedback area. Here **145**.
     ! Note that channel 21 was called, so the feedback area says: **Last Channel Selected: 21**.

  • This syntax can also be used on a touch screen, using the Num-Pad ( virtual keypad).

Set intensity for the selected channels

  • with the mouse :

Roll the mouse wheel up. In percentage mode, the selected channels increase by 1%. In Dmx mode, they increase by 1 dmx step.

Since version 0.9, the wheel is velocity-sensitive : the faster you roll it, the faster the level changes.

  • with the keyboard :
   Enter the desired intensity then press [ENTER].
   ! AT FULL keyboard shortcut : key [I]
   ! AT ZERO keyboard shortcut : key [O]
   Think of it as ON / OFF ( I/O ) switches ;-)
  • keyboard and mouse :
   Enter the desired intensity then click [AT].
  • level wheel : (see the Num-Pad )
  This level wheel is controlled over midi.

General deselection

You can deselect all selected channels at once :

  • with the mouse, from the Num-Pad :
     Click [C] (same effect as [ESC])
  • with the keyboard :
     Press the escape key : [ESC]

This function is important because it also clears the chain of commands.

Next Channel

The [LEFT] and [RIGHT] keys select the previous or next channel.

[CTRL][LEFT] or [CTRL][RIGHT] send the channel to Full. 

  If the Patch window is open, the dimmers assigned to this channel will be selected.

Multiple selections

Select all active channels

  • with the mouse :

Click [ALL].

  • with the keyboard :
     Press the [Y] key

Inverted selection : select every channel that is active but not selected

  • with the mouse :

Click [INV].

  • with the keyboard :
     Press the [U] key

Linked selection : select a range of channels that follow one another

  • with the mouse :
     Click the first channel, then drag to the last one :
     the whole range is selected.
  • with the keyboard :
     Call and select a channel : [1][2] [+]
     Type the number of the last channel of the selection : [1][8] then the [TAB] key
     Channels 12 thru 18 are selected.

Create a hard blackout and deselect everything

This function is mostly useful to clean up your channel space while setting up cues.

  • with the keyboard :
     Press [F12]

Copy Paste channels

channels can be copied and pasted on stage or in preset (BLIND mode, or if you want the buffer of the memory to come)

  • with the mouse, from the num-pad :

select the desired channels 

  click [COPY] to copy to memory
  click [PASTE] to paste from memory to the chosen buffer ( on stage, or to BLIND)
  • with the keyboard ( to stage or Blind) :
    [CTRL][C] to copy to memory
    [CTRL][V] to paste from memory to the chosen buffer ( on stage, or to BLIND)

   ! On stage you can copy to memory the channel values called from the keyboard, but also those coming from the Masters ( in orange).
   ! In Blind, only values coming from Blind can be copied to memory.

Recall channel settings from another memory ( GET )

  • with the keyboard ( to stage or Blind) :
    Select the channels
    Type the memory number
    [CTRL][G]

Information about what will happen to the channels in the next memory (the one in preset)

A channel whose intensity will rise in BLIND is marked with a small +. Conversely, a channel whose intensity will go down in the preset is marked with a small -.

Manipulations in Blind

the BLIND buffer

Access BLIND : click [BLIND] from the main commands at the top right, or press [CTRL-F11].

The BLIND buffer is where the state of all the channels of the memory to come is stored for the next crossfade. It can also be called the Preset.

It is a space where you can manipulate all the channels, as described on this page. The result does not appear on stage, because it is done in the Preset, therefore blind.

If you do not work with the CueList, the BLIND buffer will be useful to create masters blind.

  • VIEW is a mode that, when you hover over a container ( Fader dock, dock-color, memory, dock-tracker), displays its contents. It also shows where the highest level comes from for the channels driven by the masters.
   Click [View] or press [] on the keyboard

BlackOut

By pressing [F12]

  • you create a full blackout of everything on stage coming from the CueList.
  • if you are in BLIND, you clear all the channels of the memory to come.

Freeze state for channels

You can lock a selection of channels at a precise level ( a loose fixture drifting into the audience, an encoding error, …).

  • Select the channels to freeze
  • The frozen level is the highest level found between the CueList buffer and the faders buffer.
  • Click [Freeze] and confirm
  • If the selection is already frozen, it will be unfrozen.

A frozen channel appears with a small red F, and the level at which it is frozen appears in white.

Exclude channels from the action of the Grand Master

A selection of channels can be excluded from the action of the Grand Master ( color changers in concert, blues, etc…).

  • Select the channels to exclude from the action of the Grand Master
  • Click [Exclude] and confirm
  • As with Freeze, if the selection is already excluded, it will be brought back under the action of the Grand Master.

A channel excluded from the Grand Master appears with a small red circle in the top right.
