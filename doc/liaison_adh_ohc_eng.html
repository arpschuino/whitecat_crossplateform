Ad-hoc Connection

An ad-hoc connection allows you to connect up to 9 machines, using wifi network adapters in all machines.

If you are using a DMX art-net interface connected by RJ45, you will need to add a wifi router for about 25 euros, so as to share the connection to the wifi network card/adapter in White Cat. (For the moment, White Cat connects to only one network card).

Configuring an ad-hoc connection (XP)

The procedures are different between XP et Seven. In XP the configuration is a bit more complicated than in Seven.

  • open the control panel > network connections > the wireless card > Properties
  • click the wireless networks tab > advanced > computer-to-computer (ad-hoc)
  • select: do not connect automatically
  • go to > add > a name
  • set in open mode without a wep key > click ok
  • refresh network connections to display your wireless ad-hoc network, select it and log into Windows
  • In the iPod/iPhone: refresh the network connection to connect to the ad-hoc network.

If you use your machine to go on the internet while on tour, you will have to reconfigure your network adapter mode to Any access point (Wireless Networks > advanced > ). Certain wireless access points require that the IP address be assigned automatically, and not be fixed.

VISTA

  • Open the Start Menu
  • Click network connections
  • Click configure a network connection
  • Click Configure an ad hoc network (computer to computer) and Next.
  • Enter name of the network, aka “iCat connection”.
  • Check Register Network box

SEVEN

  • Open the Start Menu
  • Open the control panel > network and internet panel
  • Open Network panel
  • Click Configure a wifi Ad-Hoc network (computer to computer)
  • Click twice Next
  • Enter name of the network, aka “iCat connection”.
  • Click Share internet connection.

WIN 8

  • Type CMD on the start screen and right click on the result and select Run as administrator from the menu below.
  • Now type the following command: netsh wlan set hostednetwork mode = allow ssid = AdHoc key = password
  • Now, to start the network, type the following command: netsh wlan start hostednetwork
  • Now that ad-hoc connection is created with a password, you must share the existing connection.
  • Once the network is hosted on, you can see the Adhoc connection listed in the Network Centre and shared. Today, the ad hoc network requires an Internet connection and for that you need to share the existing active Internet connection. Right click on your existing Internet connection Wi-Fi and select Properties.
  • Now, select the Sharing tab of the properties. Check the box against “Allow other network users to connect through this computer's Internet connection.” Then select the newly created ad hoc from the dropdown connection. Now save the details and close the properties.
  • Now you can see Internet available on the new ad-hoc connection created.
  • In case you want to stop the hosted network, use this command: netsh wlan stop hostednetwork
