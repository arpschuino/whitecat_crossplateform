Configuration matérielle

Système

White Cat fonctionne sous Windows 10 et 11. À tester sous Windows 7 et Windows 8-8.1. Ne fonctionne plus sous XP, Vista.

Depuis la version 0.9.1, WhiteCat fonctionne aussi sous Linux (64 bits, x86_64) et sur Raspberry Pi (ARM64, Raspberry Pi OS Bookworm) — voir la section WhiteCat sur Raspberry Pi ci-dessous.

Les utilisateurs de très anciennes machines peuvent télécharger une ancienne version (0.8.x), toujours disponible sur le site de Christoph Guillermet.

Configuration minimum

CPU

  • Minimum théorique : dual-core 1 GHz
  • Confortable : n'importe quel CPU post-2010

RAM

  • Le show complet (512 circuits, mémoires, LFOs) tient largement dans 50–100 Mo
  • 1 Go RAM suffit, 2 Go confortable

GPU / affichage

  • SDL2 utilise le renderer hardware par défaut — n'importe quelle carte avec DirectX 9 ou OpenGL 2.0 passe
  • Une carte intégrée Intel HD Graphics de génération 2011+ suffit
  • Résolution minimum : 1280×800

Stockage

  • L'exe + DLLs + assets : ~350 Mo
  • Les shows sauvegardés : une centaine de Mo chacun

En résumé

  • Un PC bureautique d'occasion post-2010 avec Windows 10 fait tourner WhiteCat sans problème.

Configuration idéale

Pour une utilisation en conditions de spectacle (fiabilité, réactivité) :

  • CPU — Core i3/i5 gen 6+ ou équivalent
  • RAM — 4 Go
  • GPU — intégré suffit (Intel UHD 620 ou mieux)
  • Stockage — SSD
  • Écran — 1920×1080, 15"
  • OS — Windows 10 ou 11 64 bits

En résumé : un laptop bureautique milieu de gamme récent fait parfaitement l'affaire. Pas besoin de machine gaming.

WhiteCat sur Raspberry Pi

Depuis la version 0.9.1, WhiteCat tourne sur Raspberry Pi — une solution compacte, silencieuse et peu coûteuse pour piloter un spectacle.

Modèle recommandé

  • Raspberry Pi 4 ou Pi 5 — pour un affichage fluide (la version 2 Go de RAM suffit, WhiteCat est léger)
  • Le Pi 3 fonctionne mais reste limité (interface moins fluide) — dépannage ou applications autonomes (installation, boucle automatique)
  • Système : Raspberry Pi OS Bookworm 64 bits (aarch64)
  • Carte microSD rapide (classe A1/A2) ou SSD USB pour le confort

Sortie DMX

  • USB : interfaces Enttec Open/Pro, DMX King... via le pilote libftdi1 (l'utilisateur doit être dans le groupe dialout)
  • Réseau : Art-Net (Ethernet), idéal vers des nodes ou projecteurs Art-Net

Affichage

  • Raspberry Pi OS utilise le compositeur Wayland/labwc ; le placement de la fenêtre est géré par le script install.sh (voir la page d'installation)
  • Écran ou dalle HDMI, 1280×800 minimum
  • Le tracking vidéo (OpenCV) est désactivé sur Pi / Linux

Installation détaillée : voir Installer WhiteCat (section Raspberry Pi).

Tester la configuration d'un ordi

En cas d'achat dédié, il est possible de tester si WhiteCat tourne sur la machine :

  1. Copiez le dossier WhiteCat sur une clé USB.
  2. Essayez WhiteCat depuis cette clé, en magasin.

Conseils d'achat

  • Dalle mate de préférence.
  • Privilégiez les claviers rétroéclairés et les pavés numériques.
  • Pas de mises à jour automatiques Windows actives pendant le spectacle.

Lumière et vidéo sur un même portable

En utilisant VVVV et WhiteCat vous pouvez faire les deux sur un même ordi en tapant dans un processeur type i5, avec une carte graphique d'1 Go.

Pour ce genre d'application on privilégiera des machines dites pour « gamers », dont les performances graphiques 3D sont mises en avant.
