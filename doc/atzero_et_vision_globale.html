Fonctions All at Zero, Lock Presets et Vision Globale des Faders

Sur les côtés des faders ( avant le Fader 1 et après le Fader 48), vous avez accès à des commandes rapides:

ALL AT ZERO

Permet de mettre à zéro de manière sélective les 48 faders.

Lors de cette mise à zéro, un snapshot est fait de l'état de ces faders.

Ce qui permet de rappeler l'état avant mise à zéro par la commande [RECALL].

Cette fonction est prévue pour les concerts. Elle est cut, sans tempo.

Présentation

  • [FADERS]
Les 48 Faders sont mis à zéro.
Si des LFOs sont présents, sans boucle ( Loop), ils seront éteints, considérant que le mouvement est fini ( niveau = 0).
  • [SPEED]
Les 48 accéléromètres sont remis à 64 ( vitesse normale).
  • [LOCK]
Les 48 Faders sont débrayés du Lock.
  • [LFO]
Les LFOs des 48 Faders sont mis à zéro.
  • [LOOP]
Toutes les boucles des 48 Faders sont déselectionnées.
  • [ALL]
Tout en même temps.
  • [MIDI OUT]
Le renvoi midi out des faders est désactivé sur les 48 faders.
  • [RECALL]
Lors des actions [ALL AT ZERO] décrites ci dessus, une sauvegarde est faite en mémoire vive de l'état de ce que l' on va mettre à zéro.
On rappelle alors l'état avant mise à zéro.

Affecter les commandes en midi

  1. Clicker [MIDI CFG]
  2. Sélectionner la page [BUTTONS CONFIG]
  3. Clicker Attribute en solo
  4. Survoler le bouton désiré ( il apparait encadré en rouge )
  5. Appuyer sur la touche clavier désiré
  6. Clicker le bouton à affecter
! Attention, concernant la commande [RECALL] avec une BCF 2000, vous aurez besoin d'activer la transformation Key_ON Vel 0 = Key_Off dans  dans Preset / Options ( [ Midi CFG ])

LOCK PRESETS

Les états de Lock sont aussi enregistrables dans 8 Lock Preset.

On peut rappeler ces prépas d'un simple click, ou via une touche midi.

Enregistrer un état de lock

  1. Mette en lock les faders désirés
  2. Taper [F1] ou clicker [STORE]
  3. Clicker le lock preset désiré

Vider un lock preset

  1. Taper [F4] ou clicker [CLEAR]
  2. Clicker le lock preset désiré

On / Off d'un lock preset

  1. Clicker le lock preset ou utiliser son raccourci midi
  2. Attention, lors d'un appel de Lock Preset, le Master Lock est mis à Full ! Lors de la création de vos Lock Presets, assurez vous donc d'être sur un dock vide.

Affecter une commande midi à un lock preset

  1. Sélectionner le menu [MIDI_CFG]
  2. Choisir la page [BUTTON CONFIG]
  3. Choisir le mode ( 1/1 , tranches de 8, les 48 )
  4. Appuyer la touche midi désirée
  5. Clicker le lock preset désiré

VISION GLOBALE

Sur les côtés un petit panneau présentant l'état de sortie des 48 faders permet :

  • au survol de la souris d'afficher le dock sélectionné de ce fader, le type de données ( mémoire stockée, circuit, trichromie, art-net ….) , ainsi que le descriptif texte de ce dock.
  • lorsque vous clickez dessus, la page se déplace au fader appelé.

Ce panneau peut servir aussi de zône d'action rapide, évitant les menus de confirmations, lorsque:

  • [F1] ou [STORE]
  • [F2] ou [MODIFY]
  • [F3] ou [REPORT]
  • [F4] ou [CLEAR]
  • la fenêtre TIME et [AFFECT] enclenché

…. clicker la case du fader affectera l'action choisi sur le dock actif du fader.
