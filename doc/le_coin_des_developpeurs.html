Nos recettes pour Git

Git permet un travail efficace à plusieurs mains. Ce système est utilisé par les contributeurs directs du noyau Linux, et … ça marche.

À la page des recettes pour Git, nous ajouterons des méthodes simples, pour survivre et même plus. La page est structurées en deux parties, une pour l'utilisation en ligne de commande, l'autre pour l'utilisation à l'aide d'environnements graphiques.

Buts que nous pourrions viser, en janvier 2014

  1. mise au propres des métadonnées dans chaque fichier : licence, auteurs
  2. échange de « bonnes habitudes » entre personnes qui utilisent le dépôt GitHub en même temps. Le but est de ne jamais perdre le contrôle d'une version « qui marche », pendant qu'on entreprend des modifications.
  3. discussions pour évaluer les difficultés qui nous attendent
  4. et comme on dit, « un dessin vaut mille mots »
