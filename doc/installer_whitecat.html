Installer WhiteCat

Format du fichier téléchargé

  • WhiteCat est téléchargé sous forme d'archive .zip depuis GitHub.
  • Il n'y a pas de programme d'installation.
  • Cela permet de garder plusieurs versions coexistantes sur le même ordinateur — utile quand des spectacles ont été créés avec des versions différentes.
  • Le dossier WhiteCat peut aussi fonctionner depuis une clé USB.

Installer

  • Dézippez l'archive directement sous la racine d'un disque dur (C:/ ou D:/).
  • Évitez les dossiers dont le chemin contient des accents ou des espaces.
  • Ne lancez pas WhiteCat directement depuis l'archive compressée — Windows permet de naviguer dans un .zip sans l'extraire. Premier indice : le programme affiche Can't load fonts/doom.ttf et s'arrête.

Pour extraire : clic droit sur l'archive > Extraire tout > choisir un emplacement sous C:/ ou D:/.

Gestion des firewalls

Il faut autoriser WhiteCat auprès du firewall Windows (et de tout antivirus ou firewall tiers installé sur la machine).

WhiteCat ouvre des ports réseau pour recevoir et émettre du DMX en ethernet (protocole ArtNet). Le pare-feu peut trouver cela suspect et bloquer le démarrage.

  • Au premier lancement, une fenêtre Windows demande si vous souhaitez autoriser WhiteCat à accéder au réseau. Répondre Oui (ou Autoriser l'accès) et cocher Réseaux privés.
  • Si WhiteCat reste bloqué au démarrage sans cette fenêtre, vérifiez les règles du firewall manuellement et ajoutez une exception pour l'exécutable WhiteCat.

Lancer WhiteCat

Double-cliquez sur Whitecat_Crossplatform.exe dans le dossier extrait.

Pour créer un raccourci sur le bureau :

  • Clic droit sur l'exécutable > Créer un raccourci
  • Glisser ce raccourci sur le bureau ou dans la barre des tâches

Installer les drivers DMX et MIDI

Pour émettre du DMX avec une interface USB, le driver de cette interface doit être installé sur l'ordinateur. Voir Configuration DMX pour la liste des interfaces supportées.

La plupart des interfaces MIDI sont reconnues automatiquement par Windows sans installation manuelle. Pour certains périphériques peu communs, installez le driver fourni par le fabricant — toujours en télécharger la version la plus récente sur le site du fabricant.

Conseils généraux pour l'installation des drivers :

  • Faites les installations chez vous, calmement, connecté à internet.
  • Lancez les installateurs avec des droits d'administrateur (clic droit > Exécuter en tant qu'administrateur).
  • Après installation, redémarrez l'ordinateur.
  • Si vous partez en tournée internationale, gardez l'installateur du fabricant sur une clé USB.

Vous pouvez vérifier que vos périphériques sont correctement installés via le Gestionnaire de périphériques : clic droit sur le menu Démarrer > Gestionnaire de périphériques. Un périphérique défaillant apparaît avec un triangle d'avertissement jaune.

Mises en veille

Depuis la version 0.9.x, WhiteCat semble mieux supporter les mises en veille qu'auparavant. Par précaution, il est tout de même recommandé de désactiver la mise en veille pendant un spectacle.

  • Panneau de configuration > Options d'alimentation > modifier les paramètres du mode > mettre Jamais pour la mise en veille, sur batterie ET sur secteur.
  • Ne refermez jamais le capot de l'ordinateur avec WhiteCat allumé.

Optimisation des ressources

Depuis la version 0.9.x, WhiteCat intègre un ticker intelligent à trois niveaux :

  • 60 fps tant que l'utilisateur interagit (souris, clavier)
  • 25 fps pendant les animations automatiques (LFO, chasers, crossfades, dampers)
  • Mode quasi-idle (100 ms) dès qu'aucune animation n'est active

La consommation CPU est nettement réduite par rapport aux versions précédentes.

Si vous observez tout de même des ralentissements :

  • Coupez le Wi-Fi pendant le spectacle.
  • Désactivez les analyses antivirus en temps réel.
  • Désactivez les mises à jour automatiques Windows.
