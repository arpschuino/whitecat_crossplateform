Patching a moving fixture (devices)

Since version 0.10, White Cat also patches moving fixtures (moving heads, LED washes, motorised profiles, etc.) described by a GDTF file (the fixture exchange standard, used by most consoles and visualisers).

Model « 1 fixture = 1 channel ». A whole fixture is controlled by a single channel: this channel carries its intensity and is used to select it. All its other parameters (position, colour, gobo, prism…) are set in the Control Fixtures window (see its dedicated page). In the channels area, a fixture therefore takes up only one cell. In the patch window, it is marked by a green banner (fixture name + range of addresses used).

Opening « Patch a device »

In the Patch area, click [Patch a device]. A library window opens.

Choosing a fixture from the library

The library is shown in three columns: 

     Manufacturer  ->  Model (Fixture)  ->  DMX Mode
     (Generic / Martin / Robe / ETC …)      (Standard, Extended, RGB…)
  • The search box filters the list as you type.
  • The All / Local filter lets you show only the fixtures already present locally, or the full library.
  • Each fixture can have several modes (different DMX channel counts): choose the one matching your fixture's setting.

The online GDTF Share library

The list transparently mixes local fixtures (files already present) with the thousands of online fixtures from GDTF Share. Downloading happens automatically when you patch; the fixture is then cached and reusable offline.

  • You need a free account on gdtf-share.com (the same as for the website).
  • Log in via the login button (username + password; the eye reveals the password). Credentials are stored locally.
  • [Update] refreshes the index of fixtures available online.
  • Without a network, you work with the fixtures already cached (Local filter).

Addressing and patching

White Cat automatically suggests the first free DMX address and the first free channel. You can:

  • set a start address and a channel;
  • define an offset and a quantity to patch several identical units, evenly spaced.

Click [Patch]: the fixture (or the batch) is patched. The green banner appears in the channels area.

Unpatching a fixture

Select one of the fixture's outputs in the patch area, then click [CLEAR]: the whole fixture (all its channels) is removed at once.
